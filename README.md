#  CODSOFT - Landing Page

This project is a **Landing Page Website** developed as part of the **CodSoft Web Development Internship (Level 1 – Task 2)**.
The main objective of this project is to design a visually appealing and responsive landing page using basic web technologies.

---

##  Project Overview

The landing page is designed to demonstrate fundamental **web development skills**, including page layout design, styling, and responsive structure. It provides a simple and clean interface that can be used as a base for modern websites.

---

##  Features

* Responsive and clean landing page layout
* Structured sections (Header, Content Sections, Footer)
* User-friendly design
* Simple and attractive UI

---

##  Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and layout design
